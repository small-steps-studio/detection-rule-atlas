# Getting started

1. Install **Detection Rule Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a YARA rule file (.yar, .yara) or a Sigma rule file (.yml, .yaml), or run **Detection Rule Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `Detection Rule Atlas` and pick a report. The button in the editor title bar of *.yar and *.yara files runs **Show Rule Summary**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **Detection Rule Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
